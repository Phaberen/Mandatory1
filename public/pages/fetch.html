Fetch

fetch in the browser

Fetch provides a promise to deliver something, Asynchronously.
this allows for a kind of "multitasking" where tasks that are usually interpreted line after line, by the runner, can now await the response.
This allows the rest of a program to run as it would, and the function then resolves as soon as the answer to the request has been received.
In plain words it is like: "do this once that has happened, then do the next thing", without blocking or stopping the rest of the program. 

fetch("/animals")
  .then((response) => response.json())
  .then((result) => console.log(result.data));

When the response from fetch arrives, .json() reads it as JSON and turns it into a JavaScript object. When that is done, we console.log the data of the result. The functions inside .then are callback functions, they run when the previous stepp is done. The same can be written with await, which waits for the answer before the next line runs.

const response = await fetch("/animals");
const result = await response.json();

fetch in Node

fetch also works in Node, so the server can get data from another website itself and send it on to the browser.

When the user makes a request to our server, we await a response for a different server,
then return with result once we have recieved our answer 

app.get("/proxy", async (req, res) => {
  const response = await fetch("https://www.google.com");
  const html = await response.text();
  res.send(html);
});

Dates

new Date() gives the current date and time as an object. Date.now() gives the time as milliseconds since 1970.

new Date()       // now, as a Date object
Date.now()       // milliseconds since 1970-01-01

getMonth() starts at 0, so January is 0. getDay gives the day of the week, where Sunday is 0.
toLocaleDateString shows the date in a readable way, like "October" if "long", or "Oct" if "short" for example .

const date = new Date();
date.getMonth()  // 0-11, 0 = January
date.getDay()    // 0-6, 0 = Sunday
date.toLocaleDateString("en-uk", { month: "long" })  // "October"
