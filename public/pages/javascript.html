Loop methods

Loop methods go through every element in an array.
map changes every item and returns a new array of same size with those changed elements.
filter returns new array with elements that match the conditions.
find gives the first match.
reduce takes a start value, here 0, and adds the value of every element number to it, resulting in one number from all the numbers combined.
forEach only does something with each item and returns nothing, so we rarely use it, since map or the others do the job better. 

const numbers = [1, 2, 3, 4];

numbers.map((number) => number * 2);              // [2, 4, 6, 8]
numbers.filter((number) => number > 2);           // [3, 4]
numbers.find((number) => number > 2);             // 3
numbers.reduce((sum, number) => sum + number, 0); // 10
numbers.forEach((number) => console.log(number)); // returns nothing

below is an example of an explicit return body with curly bracers {} which would need a return statement
for implicit return arrow function syntax we would need => number * 2
and for explicit return we would need to remember the return in the beloe snippet, so:
numbers.map((number) => { return number * 2 }); 

numbers.map((number) => { number * 2 });  // [undefined, undefined, undefined, undefined]

Server-side rendering

Server-side rendering means the server builds the whole page before sending it. readPage reads an HTML file as text, and constructPage puts header, page and footer together and puts the tab title into the header. Below is an example of the readPage, constructPage methods this very docs site uses to display pages. 

export function readPage(path) {
  return fs.readFileSync(path, "utf-8");
}

export function constructPage(page, options = {}) {
  const header = readPage("public/components/header.html");
  const footer = readPage("public/components/footer.html");

  return (
    header.replace("{{TAB_TITLE}}", options.tabTitle ?? "Node.js Docs") +
    page +
    footer
  );
}

Each page is built once when the server starts and saved as a const to be sent the moment a user visits page 

const toolsPage = constructPage(readPage("./public/pages/tools.html"), {
  tabTitle: "Tools",
});

app.get("/tools", (req, res) => {
  res.send(toolsPage);
});

Server-side rendering is good when the user should get full pages, like on this docs site. Client-side rendering seems smarter when a page has many interactive elements that need to load independently , without reloading the entire page every time.
