Node Package Manager (npm)

npm is a Command Line Interface tool(CLI) installed alongside Node.
It installs, updates and removes package s and runs scripts 

npm init -y

package.json

npm i express
npm i -D nodemon

Scripts

"scripts": {
  "start": "node app.js",
  "dev": "nodemon -e js,json,html app.js"
}

nodemon

npm run dev
