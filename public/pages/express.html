Express

A basic server

Express is a web framework in Node. we use it by importing express from the express library. It provides us with a basic server

We can then use it as a router for our web requests.
With app.get we make a route, so when someone goes to "/"
the server sends something back with res.send 

npm i express
import express from "express";

const app = express();

app.get("/", (req, res) => {
  res.send({ data: "Hello from the server" });
});

const PORT = process.env.PORT ?? 8080;

app.listen(PORT, () => {
  console.log("Server is running on port", PORT);
});

at the bottom of the file we declare app.listen to a port we choose.
this sets the port for where the server is listening. ThePORTvariable defaults to 8080 if nothing else is set.

Sending data in a GET request

We can send small bits of data in the url. With /animals/:id the :id is a placeholder, so /animals/2 gives req.params.id = "2".

A path variable points to one specific thing, like /animals/2.
A query string filters a list, like /animals?type=dog. 

// path variable: /animals/1
app.get("/animals/:id", (req, res) => {
  res.send({ data: req.params.id });
});

// query string: /animals?type=dog
app.get("/animals", (req, res) => {
  res.send({ data: req.query.type });
});

Receiving a body

A POST request sends its data in the body as JSON text.
app.use(express.json()) parses it into a JavaScript object before it reaches our routes, so we can read it with req.body. 

app.use(express.json());

app.post("/animals", (req, res) => {
  res.send({ data: req.body });
});

REST and CRUD

CRUD meanscreate, read, update, delete
In REST the url names the thing, like /animals, and the method (GET, POST, PUT, PATCH, DELETE) says what we want to do with it

The server answers with a status code to say how it went, like 404 when nothing was found or 204 when it worked but there is nothing to send back. 

GET    /animals       read all
GET    /animals/:id   read one
POST   /animals       create
PUT    /animals/:id   replace
PATCH  /animals/:id   update
DELETE /animals/:id   delete

res.status(404).send({ errorMessage: "No animal found" });
res.status(204).send();

Redirection

A redirect sends the user to another page. The server can do it with res.redirect, or the browser can do it itself with JavaScript, like window.location.href = "/".

href adds thge new page to the end of the list of pages visited
replace swaps the current page in the list for the new one.
in other words, using replace stores the previous page/endpoint so you can tab back to it
using redirect never actually serves you the page, so you get sent straight to the "/" endpoint, with no option of going "back" 

// server-side
app.get("/outdated-page", (req, res)   => {
  res.redirect("/");
});
// client-side
window.location.href = "/";
location.replace("/");
